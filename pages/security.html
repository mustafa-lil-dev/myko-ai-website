How to report a vulnerability.

Reporting a vulnerability

If you find a security issue in Myko AI or this website, please open a private security advisory on the GitHub repository rather than a public issue, so it can be addressed before details are disclosed publicly.

Scope

This covers the Myko AI desktop application and this website's source. It does not cover third-party AI model providers you choose to connect to your own account.

What to expect

Reports are reviewed on a best-effort basis by the maintainer. There is no bug bounty program at this time.
