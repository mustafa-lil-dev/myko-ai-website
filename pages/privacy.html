Privacy

Short version: we don't collect anything.

No telemetry

Myko AI does not collect usage analytics, crash reports, or any other telemetry from the desktop app. There is no account system and no backend server operated by this project.

Model providers

When you use an AI feature, the prompts and relevant file context you send are transmitted directly to whichever model provider you've configured (a hosted API you bring your own key for, or a local model server such as LM Studio). That data is subject to the privacy policy of the provider you chose, not this project.

This website

This site is static and served without a backend. It may make a single anonymous request to the public GitHub API to display the repository's star count; no other data is transmitted.

Changes

If this policy changes, the update will be reflected on this page with a new date in the project's changelog.
